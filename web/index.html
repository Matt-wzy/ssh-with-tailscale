SSHWithTailscale

内置 Tailscale 的 Android SSH / SFTP 客户端。
不抢占系统 VPN 槽位，无需另外开启 Tailscale 客户端即可开始连接。

⬇ 下载 APK 使用说明

它怎么工作？

把 Tailscale 直接嵌进 App 进程，在本地起一个 SOCKS5 代理，SSH 流量经进程内 WireGuard 隧道到达 tailnet。

功能特性

🔐

SSH over tailnet

经 SOCKS5 走 WireGuard 隧道连到 100.x.x.x，支持密码与 PEM 私钥认证，内置自绘终端（可长按选择复制）。

🔁

端口转发

本地 -L 与远程 -R 规则可持久化，每次 SSH 连接自动下发，无需重复配置。

🌐

反向导出

手机在 tailnet 上监听端口，既作中继转发到局域网设备，也可作 HTTP 代理让其它节点经手机出网。

📁

SFTP 文件管理

浏览、上传、下载，多文件并行；大量碎文件自动在服务器端 tar 打包后下载、本地解包。

📡

Tailnet 设备列表

查看在线节点，点选即可把目标地址填入 SSH 主机，免去手抄 100.x.x.x。

🛡️

主机密钥校验

TOFU（首次连接信任）策略记录 SSH 主机指纹，密钥变更时拒绝连接并给出恢复步骤。

为什么需要它？

Android 同一时刻只允许一个 VpnService。当系统 VPN 槽位已被占用时， 官方 Tailscale App（同样基于 VpnService）就无法同时运行，只能来回切换。

本项目的做法是把 Tailscale 直接嵌进 App 进程内：以 userspace（netstack）模式拉起 Tailscale 节点， 并在 127.0.0.1:1055 起一个本地 SOCKS5 代理。SSH 客户端把连接指向这个 SOCKS 代理， 流量就经进程内 WireGuard 隧道到达 tailnet，而不抢占系统 VPN 槽位。 无需 root、无需系统 VPN、无需切换，也无需另外开启 Tailscale 客户端。
