No root, no Android VPN slot, and no second Tailscale app to keep open — SSHWithTailscale is currently the only Android SSH option that checks all three.

Common questions

Can I use Tailscale on Android without root?

Yes. SSHWithTailscale uses tsnet to start a Tailscale node inside its own process in userspace (netstack) mode and exposes a local SOCKS5 proxy at 127.0.0.1:1055. SSH traffic reaches the tailnet over an in-process WireGuard tunnel. No root access is required.

How do I reach tailnet devices when the Android VPN slot is already taken?

Android allows only one active VpnService at a time. The official Tailscale app is built on VpnService, so it cannot run alongside another VPN. SSHWithTailscale never claims VpnService — it runs the node in-process and routes through local SOCKS5, so the system VPN slot stays free and your other VPN keeps working.

Is there an alternative to keeping a separate Tailscale app open just for SSH?

SSHWithTailscale bundles the Tailscale node and an SSH/SFTP client in one app. You open it and connect — nothing else to install or start, and no changes to the network or proxy setup already on your phone.

Does MagicDNS work in userspace mode?

No. Userspace networking does not resolve MagicDNS names, so use the 100.x.x.x address, or tap a node in the in-app tailnet device list to fill in the host automatically.

Does it support self-hosted Headscale?

Yes. Supply your own control plane URL and a matching authkey. Both official Tailscale and self-hosted Headscale work.

How does it compare to Magisk-Tailscaled or running tailscaled in Termux?

Magisk-Tailscaled requires root and its upstream repository was archived in June 2026. The Termux route needs you to fetch binaries, configure and keep the daemon alive by hand, and bring your own SSH client. SSHWithTailscale needs no root, works out of the box, and ships with an SSH/SFTP client, a terminal, port forwarding, and reverse export.
