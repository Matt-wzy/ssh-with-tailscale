SSHWithTailscale

An Android SSH / SFTP client with Tailscale built in.
No system VPN slot taken, no separate Tailscale app needed to start a connection.

⬇ Download APK Docs

How it works

Tailscale is embedded inside the app process; a local SOCKS5 proxy carries SSH traffic through an in-process WireGuard tunnel to your tailnet.

Features

🔐

SSH over tailnet

Connect to 100.x.x.x through the SOCKS5 → WireGuard tunnel. Password and PEM key auth. Built-in terminal (long-press to select/copy).

🔁

Port forwarding

Local -L and remote -R rules persist and re-apply on every SSH connection — no repeated setup.

🌐

Reverse export

The phone listens on a tailnet port — relay to LAN devices, or act as an HTTP proxy so other nodes exit through the phone.

📁

SFTP file manager

Browse, upload, download in parallel; lots of small files are tar-packed on the server, then extracted locally.

📡

Tailnet device list

See online nodes and tap one to fill the SSH host — no manual typing of 100.x.x.x.

🛡️

Host key check

TOFU records the SSH fingerprint; a key change is rejected with recovery steps.

Why you need it

Android allows only one VpnService at a time. When the system VPN slot is taken, the official Tailscale app (also based on VpnService) can't run alongside it — you end up switching back and forth.

This project embeds Tailscale directly inside the app process: it starts a Tailscale node in userspace (netstack) mode and opens a local SOCKS5 proxy at 127.0.0.1:1055. The SSH client points at that proxy, so traffic travels through an in-process WireGuard tunnel to your tailnet without taking the system VPN slot. No root, no system VPN, no switching, and no separate Tailscale app.
