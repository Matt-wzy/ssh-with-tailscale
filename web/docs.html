使用说明

以下说明基于 v1.0.0。遇到问题可到 GitHub Issues 反馈。

1. 安装

  1. 到 Releases 下载 app-release.apk。
  2. 在系统设置里开启「未知来源」安装权限（不同厂商入口不同）。
  3. 用 adb 安装，或直接点开 APK 安装：
    adb install -r app-release.apk

应用 ID 为 org.dpdns.mattsgateway.sshwithtailscale。

2. 首次连接

  • 打开 App → 填入 Tailscale 节点的 auth key（或用已登录账号）。
  • 节点起来后，App 会在 127.0.0.1:1055 起本地 SOCKS5 代理。
  • 新建 SSH 连接：填写主机（如 100.10.20.30）、端口、用户名，选择密码或 PEM 私钥认证。
  • 首次连接会弹出主机指纹确认（TOFU），确认后写入本地信任列表。

3. 终端与复制

连接成功后进入自绘终端（TERM=xterm-256color）：

  • 长按屏幕进入选择模式，拖动设置起止位置。
  • 选区内会出现「复制 / 取消」操作条，点「复制」写入剪贴板。

4. SFTP 文件管理

  • 浏览远端目录，下拉刷新列表，可按名称排序。
  • 多文件并行上传 / 下载；下载目录可用 SAF 自由选择。
  • 大量小文件自动在服务器端 tar 打包后下载，本地再解包，显著提速。

5. 端口转发 (-L)

在连接配置里添加本地转发规则，例如把远端 3306 映射到本机 localhost:13306：

本地 13306 → 远端 100.10.20.30:3306
规则持久化保存，下次连接自动下发。（远程 -R 代码已保留，暂未开放 UI。）

6. 反向导出

  • 中继模式：手机在 tailnet 上监听端口，把连接转到手机局域网内的某台设备。
  • HTTP 代理模式：让其它 tailnet 设备经手机自身网络出网。

7. Tailnet 设备列表

在「设备」页查看当前在线节点；点击任一节点即可把它的 100.x.x.x 地址填入新建连接的「主机」字段。

8. 主机密钥校验

App 记录每台主机的 SSH 指纹（TOFU）。若服务器重装 / 重装 SSH 导致指纹变化，连接会被拒绝并提示： 删除旧的信任记录后再连即可。

9. 自行构建

需要 Go 1.26+、Android SDK、NDK 与 JDK 17+。完整步骤见 仓库 README · 构建：

GO_BIN_DIR=~/tools/go/bin ./generate_aar.sh ./build.sh all # 同时构建 debug 与 release
